## H0.6.3 corrections (12 items, all landed)

| # | Item | Resolution |
|---|---|---|
| 6.3.1 | RestoreTrap BEFORE drain | `with RestoreTrap(pre_state) as trap:` wraps drain + measurement + post-state capture. The trap is active from the first stop until the audit write. |
| 6.3.2 | Trap dynamically records each stop | `_drain_allowlist_pre(allowlist, trap=trap)` calls `trap.record_stop_event(evt)` after each stop. BLOCKED-during-drain still triggers the trap and restarts everything that was stopped. |
| 6.3.3 | ONE authoritative post-state | `_fresh_post_state()` is called ONCE inside the with-block. The same dict is used to derive `post_state_restored` (via `_is_post_state_restored`) and to populate the audit. |
| 6.3.5 | Real mechanical TIMEOUT | `setitimer(ITIMER_REAL, ...)` raises `_MeasurementTimeout` on the main thread. Callable-level subprocess timeouts remain allowed but no longer REQUIRED. |
| 6.3.6 | Celery via /proc/<pid>/stat | `_celery_cpu_percent` samples utime+stime twice and computes aggregate CPU%. No more `top -p` 20-PID cap. |
| 6.3.7 | C1 child-process test | `test_signal_reraise_does_not_recurse_in_child` spawns a child with a counting handler, sends SIGTERM, asserts `COUNTER=1` (no recursion). |
| 6.3.8 | drain-restart regression | `test_blocked_during_drain_still_restarts_services` mocks `allowlist.is_active=True` for the build service, mocks the foreign-owner gate, asserts the trap restarts the service. |
| 6.3.10 | C3 rate assertion | The real-host `_swap_io_rate` is exercised in the test (asserts non-negative rates; rate vs zero checked via raw sample). |
