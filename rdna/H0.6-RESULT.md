## Pipeline (H0.6.2)

```
snapshot pre_state
  ↓
acquire exclusive flock (~/.cache/hyperloom/evaluator.lock)
  ↓
resolve allowlisted service MainPIDs/PGIDs (BEFORE stop)
  ↓
stop allowlisted services (systemctl stop, never pkill)
  ↓
wait briefly for pre_stop_pids/PGIDs to clear
  ↓
attribute foreign PIDs (BDF-resolved; UNKNOWN if not attributable)
  ↓
BLOCK if any UNKNOWN or foreign owner remains
  ↓
with RestoreTrap(signal handlers active, services_to_restart queued):
  ctx.register_candidate_pid(pid)   <- callable launches subprocess
  ctx.register_candidate_pgid(pgid) <- in start_new_session() group
  run measurement callable
  - measures; if subprocess.Popen with timeout, exits 137 on deadline
  ↓
trap __exit__: SIGTERM → grace → SIGKILL the PGID, restart services,
                    release lock
  ↓
verify candidate port is gone + no descendant XTX owners
  ↓
fresh post-state probes (service_state + listener_state + health +
                          gpu_telemetry + attribute_to_lab_gpu)
  ↓
emit lifecycle audit artifact
```

## H0.6.2 corrections summary

| # | Item | Resolution |
|---|---|---|
| 6.2.1 | Trap AROUND measurement | The orchestrator now wraps `measurement(ctx)` in `with RestoreTrap(...)`. Signal handlers are installed before launch and uninstalled after exit. |
| 6.2.2 | Mutable candidate PID | `RestoreTrap.set_candidate_pid(pid)` / `set_candidate_pgid(pgid)` are closures over the live trap. The `MeasurementContext.register_candidate_pid` and `register_candidate_pgid` delegate to them. |
| 6.2.3 / 6.2.4 | Process-group kill | `h05_baseline` launches the subprocess with `start_new_session=True`. `RestoreTrap._kill_candidate()` prefers `os.killpg(pgid, SIGTERM)` → `os.killpg(pgid, SIGKILL)`. The whole subtree (wrapper + bypass + llama-server + driver threads) is reaped. |
| 6.2.5 | Post-kill verification | `_verify_port_closed()` polls the candidate port to prove the kill was real. Plus fresh `attribute_to_lab_gpu` and force `Outcome.FAIL` if any descendant XTX owner remains. |
| 6.2.6 | Wait on pre-stop PIDs | `_drain_allowlist_pre` resolves MainPIDs / PGIDs BEFORE `stop_service()`. `_wait_for_pids_to_clear` uses that pre-stop set, not the post-stop empty values. |
| 6.2.7 / 6.2.8 | Exact-token fixture by path | `custom_rx7900xtx.sh` reads `$FIXTURE_PATH` (default empty → back-compat). `bench/measure.py:bench` accepts an optional 4th positional arg = fixture path; loads via `load_fixture()`, fails closed on GGUF mismatch. `cli.py:--fixture-path` propagates via `HYPERLOOM_FIXTURE_PATH`. |
| 6.2.9 | H0.5 per-rep gate | `h05_baseline` now passes `identity_provider=lambda: ident` to `run_repeat`. E2E confirmed: the H0.5 gate fired inside the subprocess and BLOCKED with the correct reason. |
