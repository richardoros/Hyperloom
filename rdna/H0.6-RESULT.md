## Pipeline (implemented in `rdna/h06/orchestrator.py:run_lifecycle`)

```
snapshot pre_state
    ↓
acquire exclusive flock (lock.py) [BLOCKED if held by another evaluator]
    ↓
attribute foreign PIDs to lab GPU (ownership.py)
    ↓
stop allowlisted services (allowlist.py — empty by default)
    ↓
BLOCK if unknown owners remain (operator must kill or allowlist)
    ↓
run H0.5 measurement (caller-supplied callable)
    ↓
on exit (SUCCESS / FAILURE / TIMEOUT / SIGTERM / SIGINT / exception):
    - kill candidate PID (restore.py:RestoreTrap)
    - restart stopped services
    - release lock
    ↓
verify production (18079 listening, /health passes, no unknown owners)
    ↓
emit lifecycle audit artifact (lifecycle_<id>.json)
```

## Modules landed

| Module | Purpose |
|---|---|
| `snapshot.py` | Pre-state snapshot (GPU UUID/BDF/board, ROCm-attributed PIDs, telemetry, services, listeners, prod health probe). |
| `lock.py` | `flock`-based exclusive experiment lock. Default `~/.cache/hyperloom/evaluator.lock`; overridable via `HYPERLOOM_EVALUATOR_LOCK`. Second evaluator refuses non-blocking. |
| `ownership.py` | Real PID→GPU via ROCm (`rocm-smi --showpidgpus`) + DRM scan (`/proc/<pid>/maps` → `/dev/dri/cardN`). `_drm_card_to_bdf` maps DRM device path → PCI BDF. Per-process attribution replaces H0.5's `-ngl` heuristic. |
| `allowlist.py` | `stop_service` / `start_service` via `systemctl`. `DEFAULT_ALLOWLIST()` is **empty** — `qwen38-turboquant.service` is intentionally NOT in the default. Never `pkill`. |
| `restore.py` | `RestoreTrap` is idempotent; installs SIGTERM/SIGINT/SIGHUP handlers; kills candidate PID via SIGTERM→SIGKILL grace; restarts stopped services. |
| `orchestrator.py` | Pipeline glue; ensures every path flows through the post-try audit write. `LifecycleAudit` carries `outcome` + `reason` + every observable signal. |
| `cli.py` | `measure --experiment-id N --measurement echo_success|echo_fail --artifact-dir PATH` dry-run entry point. |
| `tests/test_h06.py` | 20 unit tests covering snapshot, lock, ownership (5 tests), allowlist, restore, orchestrator (5 outcomes). |

## What is NOT in H0.6

* **Real measurement callable.** The dry-run uses `echo_success` /
  `echo_fail`. Real H0.5 measurements belong to H0.7 (the agent loop
  driving A/B/A experiments).
* **PID-to-GPU-UUID map for Vulkan-only processes.** Vulkan KMDs do not
  register with KFD, so the GPU UUID attribution relies on
  /proc/<pid>/maps + DRM card→BDF mapping. UUID attribution for Vulkan
  processes requires a per-device `/sys/class/drm/card*/device/uevent`
  walk (currently implemented at the BDF level, not UUID level).
* **Auto-drain of qwen38-turboquant.service.** The production service
  is intentionally NOT in `DEFAULT_ALLOWLIST()`. The operator must add
  it explicitly with a one-line comment to drain production for an
  exclusive-XTX window.
* **A/B/A interleaving as a hard PROMOTE gate.** Owned by H0.5.
* **Product-quality gate.** Owned by H0.5.

## How to wire a real measurement

Once the lab GPU is free (foreign workloads stopped or allowlisted),
pass any of the H0.5 measurement callables as `--measurement`:

```python
# rdna/h06/cli.py currently exposes 'echo_success' / 'echo_fail'.
# Future: 'h05.baseline' / 'h05.candidate' (H0.7 work).
```

Real measurement callable contract:

```python
def measurement(ctx: dict) -> int:
    """ctx: pre_state_captured_utc, lab_gpu_uuid, lab_gpu_bdf, foreign_owners,
            experiment_id, allowlist, ...
    Returns the candidate's exit code (0 on success).
    Raises on failure; the trap will catch and restore.
    """
```

The lifecycle audit artifact records every observable signal the
measurement callable produced.
