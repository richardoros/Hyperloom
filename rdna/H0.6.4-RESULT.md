## Authoritative lifecycle (as implemented)

```text
pre-state
   -> acquire lock
   -> enter RestoreTrap
   -> drain allowlisted services      (6.4.9 fail-closed on stop failure)
   -> survivors -> foreign-owner gate -> measurement
EXIT RestoreTrap
   -> kill candidate / PGID, restart stopped services
   -> resolve new MainPIDs of restarted services       (6.4.4)
   -> verify candidate port closed + no descendants    (6.4.3)
   -> ONE fresh post-state snapshot                    (6.4.2, 6.4.10)
   -> verify expected XTX ownership + pre/post match   (6.4.4)
   -> derive final outcome; restoration failures dominate (6.4.11)
   -> write same evidence to audit -> release lock
```
